webserv

Minimal HTTP/1.1 server written in C++98. Test endpoints:

  • /kapouet/ — location with its own root
  • /gallery/ — autoindex on
  • /old — 301 redirect
  • POST /uploads/<name> — file upload
  • DELETE /uploads/<name> — file delete
  • /cgi-bin/hello.py — CGI
  • /does-not-exist — custom 404 page
  • /crew/— 42 crew
